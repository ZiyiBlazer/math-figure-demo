# 数学图形生成系统（演示版）

为教培例题自动生成**准确、可靠**的数学图形，替代"上传图片 + 让 AI 改图"的老方案——老方案让 AI 猜像素，坐标不准、比例不对、每次结果还不一样。

## 在线演示

点开即用（电脑、手机浏览器均可）：

👉 https://ziyiblazer.github.io/math-figure-demo/

## 怎么使用

**方式一：统一入口**

页面顶部输入框粘贴题目 / 函数表达式 / 图形描述，或粘贴一张例图，选择类型（平面几何 / 函数图像 / 立体曲面），点「生成」即可。

**方式二：分引擎操作**

| 类型 | 怎么做 | 可修改项 |
| --- | --- | --- |
| 平面几何 | 输入英文几何题 → 生成 | 字母标注（如 A→P）、边标注（如 4→2a） |
| 函数图像 | 输入表达式（如 `sin(x)`、`x**2-4`）→ 画图 | 坐标轴字母、自动标出零点与极值点 |
| 立体 / 曲面 | 选长方体 / 四棱锥 / 抛物面 → 生成 3D | 顶点字母 |

## 核心思路

1. **AI 出图纸** —— AI 只读懂题目，输出结构化的「图纸规格单」，不碰像素
2. **引擎精确画** —— 平面几何用自研 SVG 引擎算坐标，函数 / 立体用数学库，画得准
3. **自动校验** —— 平行、直角、比例逐项校验，不合格不交付

同一份图纸画 100 次，结果都一样。

## 关于本演示

- 单文件 HTML，无任何外部依赖，双击 `index.html` 即可离线打开
- 演示版用本地规则模拟 AI 解析，完整展示「理解 → 画图 → 校验」流程；正式版将接入真实 AI 模型
